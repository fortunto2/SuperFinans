# Транзакции

Отслеживайте доходы и расходы, чтобы понимать, куда уходят деньги, и находить больше средств для накоплений.

## Добавление транзакции
![plus.circle.fill]
Нажмите + на вкладке Транзакции. Сначала появится цифровая клавиатура для быстрого ввода суммы. Затем выберите категорию, дату и при желании добавьте заметку.

## Категории
![square.grid.2x2.fill]
SuperFinans включает 20 встроенных категорий: Продукты, Рестораны, Жильё, Транспорт и другие. У каждой своя иконка и цвет.

## Доходы и расходы
![arrow.up.arrow.down]
Положительные суммы — это доходы, отрицательные — расходы. Баланс счёта обновляется автоматически.

## Счета
![building.columns.fill]
Распределяйте транзакции по счетам: до 3 в бесплатной версии (безлимит с Premium). Создавайте текущие, сберегательные, кредитные счета или наличные.

## Группировка по дате
![calendar]
Транзакции группируются по дням для удобного просмотра ежедневных трат. Переключайтесь между месяцами для анализа истории.

## Повторяющиеся транзакции
![repeat]
Настройте шаблоны для регулярных платежей: аренда, зарплата, подписки. SuperFinans отслеживает расписание и напоминает о предстоящих платежах.
